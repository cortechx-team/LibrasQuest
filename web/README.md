# LibrasQuest Web

Frontend do projeto LibrasQuest, construído com Next.js (App Router), React e Tailwind CSS.

## Scripts

- `npm run dev`: inicia o servidor de desenvolvimento.
- `npm run build`: gera o build de produção.
- `npm run start`: inicia o build de produção.
- `npm run lint`: executa análise estática com ESLint.

## Documentação técnica interna

Para entender o funcionamento completo dos componentes da aplicação e do módulo de câmera:

- [Documentação de Componentes e Módulo de Câmera](./docs/COMPONENTES_E_CAMERA.md)

## Execução local

1. Entre na pasta `web`.
2. Instale as dependências com `npm install`.
3. Rode `npm run dev`.
4. Acesse [http://localhost:3000](http://localhost:3000).
