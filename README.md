# LibrasQuest
Uma plataforma interativa que gamifica o aprendizado da Língua Brasileira de Sinais. Utilizando visão computacional e inteligência artificial direto na webcam, o sistema reconhece os gestos do usuário em tempo real para validar soletrações e propor desafios, como o clássico Jogo da Forca, tornando a fluência no alfabeto manual acessível e divertida
