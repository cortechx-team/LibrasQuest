# 🤟 LibrasQuest

> **An interactive and gamified platform for learning the Brazilian Sign Language (Libras), powered by Computer Vision.**

Developed by the **Computer Vision Directorate of the CortechX Academic League**, this project transforms the user's webcam into an accessibility and education tool. Through real-time hand tracking and artificial intelligence, the system validates spelling and proposes interactive challenges to teach the Libras manual alphabet.

---

## 🎯 Features (MVP 1)

The system was designed to offer an intuitive learning progression:

*   **Learning Mode:** The user must spell words generated by the system with the visual aid of photos for each Libras symbol. The AI validator confirms the correct gesture in real-time.
*   **Practice Mode:** An advanced spelling mode without the help of images, testing the user's memory retention.
*   **Libras Hangman Game:** The classic minigame. The user signs the letters to the camera to try to guess the hidden word before losing all their lives.

---

## 🛠️ Architecture and Tech Stack

The architecture was designed to ensure **low latency** in sign recognition, using a hybrid model (**client-side 3D landmarks extraction** + classic ML model) instead of heavy server-side image processing.

### Computer Vision & AI (Modeling): `Python`
*   **MediaPipe:** Extraction of hand coordinates (21 points generating 63 coordinate values).
*   **Scikit-Learn:** Classifiers trained to identify 20 static classes of the Libras alphabet (**Random Forest**).
    *   *Note: Letters with movement (H, J, X, Z) are excluded from the current static classifier scope.*
*   **uv:** High-performance environment and dependency management.

### Backend (API): `FastAPI`
*   **WebSockets:** Continuous bidirectional communication for real-time inference and ultra-low latency.
*   **SQLAlchemy & Alembic:** ORM and database migration control.
*   Asynchronous architecture supporting multiple users.

### Interface and Game Logic (Frontend/Web): `Next.js 16 (App Router)`
*   **React 19 and Tailwind CSS 4:** Modern, performant, and responsive interface.
*   **MediaPipe JS:** Integrated directly into the browser to extract coordinates locally, avoiding sending heavy raw video frames to the API.
*   Custom hooks for permission management and camera streaming.

### Database: `PostgreSQL`
*   Dedicated schema (`learning`) for user management, word dictionary, and progress tracking.

### Infrastructure: `Docker` and `Docker Compose`
*   Full containerization of all services.

## 🤖 Modeling and Machine Learning

The `/model` directory contains the core intelligence of LibrasQuest. To reproduce or improve the model:

1.  **Data Collection:** Use `dataset_tools/collect_data.py` to capture hand landmarks via webcam.
2.  **Preprocessing:** Run `model/notebooks/data_prep.ipynb` to clean data and generate features (distances and directional differences).
3.  **Training:** Execute `model/notebooks/model.ipynb` to train the Random Forest classifier and export the model.

## ⚙️ How to run the project locally

Since the project is 100% containerized, the initial setup is extremely simple.

### Prerequisites
*   [Docker](https://www.docker.com/) installed.
*   [Docker Compose](https://docs.docker.com/compose/) installed.
*   A functional webcam connected to the computer.

### Execution Steps

1.  **Clone this repository:**
    ```bash
    git clone https://github.com/cortechx-team/LibrasQuest.git
    cd LibrasQuest
    ```

2.  **Configure Environment Variables:**
    Copy the example file and fill in the database credentials:
    ```bash
    cp .env.example .env
    ```
    *Make sure the credentials in `.env` match the ones expected by the database service in `docker-compose.yml`.*

3.  **Start the entire ecosystem:**
    ```bash
    docker-compose up --build
    ```

4.  **Access the application:**
    *   **Frontend (Game):** http://localhost:3000
    *   **Python API Documentation (Swagger):** http://localhost:8000/docs
